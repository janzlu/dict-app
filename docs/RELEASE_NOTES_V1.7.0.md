# 识光 Lumina V1.7.0 🚀 全维视觉跃迁与双轨记忆引擎

本次 V1.7.0 是一场**由表及里的史诗级全面重构**。它不仅在视觉系统上跨越了原生时代的界限，在算法层面，更将“不打扰的极致克制”与“高精准的复习循环”完美融为了一体，带来真正的独角兽级桌面体验。

### 🌟 核心理念：掌控专注力，释放极客美学

- 🪟 **沉浸视界，告别呆板边框**：全系应用采用了 Apple-Style 的沉浸式无底框设计 (`frameless immersion`)，将操作系统的默认顶栏彻底抛弃。取而代之的是与控制台深空背景完全连结并无限延展的丝滑拖拽区。
- 🌓 **变色龙引擎，系统级光影随动**：新增纯正底层 IPC 挂载的亮/暗双模渲染器。不仅拥有深邃极客的黑夜模式，这次彻底重写了浅色调（Light Mode）。告别了灰褐色的灾难感对比度，现在它能够精准跟随 Windows 的日出日落模式动态跳变，所有按钮、输入框、控制面板都将在毫秒间切换至通透的白底高反差形态。
- 🎲 **艾宾豪斯双轨控制，主宰复习节奏**：
    - **主动模式**：想要边喝咖啡边复习？点下全新的“🎲 碎片时间随机复习”按钮，享受带有自动状态缓冲反馈流的无缝点按翻阅！刷清每日份额后，还会温馨提示制霸成就！
    - **沉浸屏保模式**：新增“📺 自动随机轮播”。点击后卡片将悬浮于桌面一角，彻底隐去按键，以上帝视角按照“单词 2s -> 释义 3s -> 自动下翻”的白噪音节奏无限放映词组，极致优雅！
    - **极客拦截**：厌倦了后台轮询器的“教导主任式”强行打断？新增 [艾宾豪斯自动弹窗复习] 物理级控制开关，还您完全 100% 不被打扰的专注时长！
- 🎬 **电影级互动官网迭代**：官方 Web 主页全面下架了拉伸畸变的老旧 `mp4` 演练机制。取而代之的是使用 `framer-motion` 在浏览器内核原生流式读取截图的超级幻灯片。搭配复杂的 `mix-blend-screen` 滤色与动态高斯发光背景，官网颜值直线上升。
