# DictApp Pro - 官方展示站落地方案 (Landing Page Blueprint V2.0)

针对本项目极度硬核的技术深度与沉浸式体验，官网必须跳出传统背单词软件“卡通化、拼凑感”的廉价包装模式，而对准极客开发者圈层与高密度阅读者（研究员、双语用户）的心智，打造一种“高性能、低侵入、重度黑科技”的氛围。

经过对底层代码库的深度盘点（包含多核降级容灾、本地优先 CRDT 同步机制机制），现对原视觉实施方案进行全方位修订升级。

---

## 🎨 第一维度：视觉美学与情绪板 (Design & Moodboard)

这是一套专为在深夜中沉浸于阅读的你所设计的美学标尺：

*   **基底深渊 (Void Black)**：抛弃一切灰色系，主背景设为绝对色值 `#03040B` 甚至纯黑 `#000000`。
*   **黑客霓虹 (Cyber Glass)**：在黑底上勾勒深邃的光源晕染（如幽灵般的暗紫色 `#7B2CBF` 或冷聚变蓝 `#00B4D8`），作为背景游离的虚化渐变块（Radial-Gradient Blob）。
*   **毛玻璃矩阵 (Glassmorphism 2.0)**：所有前置卡片全部使用透明加 1px 或 0.5px 高亮的白线框渲染边缘，制造薄如蝉翼的悬浮科技质感（`backdrop-blur-md`, `border-white/10`）。
*   **排版狂热 (Kinetic Typography)**：大号标题采用无衬线几何字体（如 `Outfit` / `Satoshi`），摒弃任何传统带鱼屏阅读的局促感。

---

## 🧠 第二维度：核心卖点“大揭秘” (Unique Selling Propositions - USP)

在审核代码库底层后，官网必须分为四大“特写镜头（Bento Grid）”来震撼展出你的四大隐藏核心科技：

### 🔮 【镜头一】视界劫持：3000 字长难句沉浸翻译引擎
*   **宣发文案**：绝不切断你的心流。
*   **技术亮点**：
    *   **无感触发**：基于底层进程拉起的剪贴板守望者（*Clipboard Hook*）。只需 Ctrl+C 一下，悬浮仓会像幽灵般凭空跃出。
    *   **深度长文穿透**：不再是查字典，而是查段落。最高支持对 3000 字符重度长难句进行自动折叠与换行坍塌（Flat）处理。
    *   **中英降噪混排**：代码层锁死了神经元解析节点。**如果句子中包含大量汉字，它将精准绕过汉字，只剥除英文进行翻译后再重新拼接！**

### ⛓ 【镜头二】坚不可摧的中枢：双核联控容灾算法
*   **宣发文案**：在断网沙漠里，仍然是一把尖刀。
*   **技术亮点**：
    *   **第一级引擎**：本地毫秒级反馈 SQLite 挂载阵列（无网络环境照样瞬秒发声发译）。
    *   **第二级神经引擎 (G-NT)**：全球最高效的大模型分片式词素分析直连。
    *   **第三级抗震熔断 (MyMemory Fallback)**：即便遭遇大中华区“长城防火墙”的拔网线阻击（抛出 `ECONNRESET` 异常），最底层的 `try-catch` 重路由会无感自动帮你嫁接到降级线路，完全不会闪退报错。

### ⏳ 【镜头三】逆转遗忘：SM-2 艾宾浩斯记忆降维打击
*   **宣发文案**：交出你的大脑弱点，我们来安排算法。
*   **技术亮点**：
    *   内置完整的 **SuperMemo-2 (SM-2)** 时间微积分引擎。根据你的遗忘阈值（E-Factor）与掌握层级体系，精算你的下一次抗拒遗忘（Next Review Time）并定时喂食。
    *   配合重新计算过欧几里德几何增量过滤的无缝托拽交互，打磨出极爽的翻卡体验。

### 📡 【镜头四】终身掌控：零订阅本地优先同步 (Local-first LWW Sync)
*   **宣发文案**：没有高昂月费，也没有云端勒索。
*   **技术亮点**：
    *   内置高阶版本的 **LWW (Last-Write-Wins) CRDT 映射合并算法**！
    *   应用将原生的 SQLite 解析为最小差异化 JSON。您可以将云盘目标随意插在 Dropbox, OneDrive 或 iCloud 的目录里，多台电脑的变更将通过算法“毫无冲突”地进行时间戳静默融合合并。数据隐私彻头彻尾属于您自己！

## 🛠 第三维度：落地技术栈选型

*   **框架骨架**：**Next.js (React) + Vite**。用于极其疯狂的首屏静态渲染速度。
*   **原子级样式**：**Tailwind CSS**。配合极客范黑底能飞速实现我们上面讲的光晕色块。
*   **镜头动画引擎**：**Framer Motion**。当网页滚到“双核联控算法”区域时，利用它做出类似 Apple 官网的代码块或服务器模型分体式掉落、散开的电影级入场转场。
*   **物理全球分发**：依托提交给 **Vercel** 或者托管在 **GitHub Pages**。做到推包即刻上线，实现极客精神。
